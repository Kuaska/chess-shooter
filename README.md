# Chess Shooter — рейд

Опен-ворлд шутер с видом сверху в шахматной вселенной: выбираешь фигуру, собираешь снаряжение, заходишь в рейд, ищешь лут и уходишь через эвакуацию. Есть туман войны, боты и PvP с друзьями по коду комнаты.

Игра целиком статическая и работает с GitHub Pages: клиент на Vite + TypeScript + Canvas 2D, без сервера и без ассетов.

## Управление

| Действие | Клавиатура / мышь | Телефон |

| Движение | WASD / стрелки | левый стик |
| Прицел и огонь | мышь + ЛКМ | правый стик |
| Спринт | Shift | стик до упора |
| Перезарядка | R | кнопка «Заряд» |

| Оружие | 1–4 | — |
| Аптечка / стимулятор / плита / бинт | 5 / 6 / 7 / B | — |

## Фигуры

| Фигура | HP | Стамина | Скорость | Плюс | Навык |
|---|---|---|---|---|---|
| Пешка | 100 | 100 | 174 | +20% лута | Рывок |
| Конь | 112 | 132 | 180 | дешёвый спринт | Прыжок |
| Слон | 106 | 112 | 168 | враги дольше видны на миникарте | Прозрение |
| Ладья | 150 | 82 | 152 | крепче броня | Щит |
| Ферзь | 120 | 120 | 172 | быстрая перезарядка | Залп |

Смерть — хардкорная: оружие и броня теряются, остаётся пистолет. Лут попадает в стэш только после успешной эвакуации (4 секунды в зоне выхода).

## Рюкзак, лут и снаряжение

Рюкзак на 20 слотов открывается в рейде по Tab (на телефоне — кнопка «Рюкзак»). В нём видно оружие, броню и состояние: аптечки, бинты, стимуляторы и плиты используются прямо из сетки, оружие берётся в руки, лишнее выбрасывается на землю. Выброшенное остаётся лежать и подбирается обратно.

В PvP инвентарь каждого игрока считает хост: нажатия гостя уходят по DataChannel и применяются к его бойцу, а изменения возвращаются в снимках.

## Тарковские механики

- **Кровотечение.** Часть попаданий открывает кровь (до трёх стаков). Она снимает HP со временем, пока не перевязать бинтом или аптечкой. Индикатор «кровь ×N» пульсирует в HUD.
- **Схроны и ключи.** По углам карты стоят четыре запертые комнаты. Дверь открывается только подходящим ключом (`Ключ: руины / лес / деревня / склад`), ключ тратится. Внутри — 3 сейфа с ценным лутом. Ключи падают из контейнеров и продаются в магазине.
- **Страховка.** В меню можно застраховать текущее снаряжение за 25% его стоимости. Если погибнешь в рейде, застрахованные оружие и броня вернутся в стэш. Смена снаряжения или фигуры сбрасывает страховку.

## Друзья и совместная игра

У каждого игрока есть постоянный тег из 6 символов (виден в меню в панели «Друзья»). По нему можно добавить друга — он сохраняется в браузере. Точка рядом с ником показывает, онлайн ли друг: сервис шлёт heartbeat в публичный канал ntfy, поэтому отдельный сервер не нужен.

В лобби у хоста есть список друзей с кнопкой «Пригласить»: приглашение приходит другу всплывающим окном с кнопкой «Войти». Ссылка на комнату (`?room=КОД`) тоже подключает автоматически.

**Режимы:** PvP — каждый сам за себя; кооператив — все люди в одной команде, урон по своим отключён, боты и король общие. Режим переключается в лобби до старта.

## Звук

Все звуки синтезируются в WebAudio, файлов нет: выстрелы каждого оружия, «чвак» попадания по плоти, смерть, перезарядка, подбор, открытие двери, эвакуация, шаги. Громкость и беззвучный режим хранятся в сохранении, громкость настраивается в меню.

## Карта

128×128 тайлов, четыре биома, центральный дворец с королём-боссом, три точки эвакуации, которые открываются по таймеру (110 / 230 / 350 секунд). Рейд длится 10 минут — не успел выйти, погиб.

Туман войны честный: стены и деревья перекрывают обзор, уже увиденные места остаются в памяти и на миникарте.

## PvP с друзьями

1. Один игрок нажимает «Создать PvP-комнату» и получает код из 5 символов.
2. Остальные вводят код в поле «Присоединиться», открывают ссылку-приглашение или заходят через кнопку в приглашении от друга (до 4 игроков).
3. Хост нажимает «Начать рейд» — все попадают на одну карту с общими ботами.

Соединение — прямое (WebRTC DataChannel), хост авторитетен: он считает симуляцию и рассылает снимки состояния 30 раз в секунду. Для обмена сигналами используется публичный ntfy (`ntfy.envs.net`, HTTP + SSE), поэтому сервер не нужен.

Ограничения PvP:

- вкладка хоста должна оставаться открытой;
- если хост погибает или выходит, рейд для остальных заканчивается;
- публичный ntfy имеет лимиты запросов и не гарантирует доставку — для дружеских игр этого достаточно, но при перегрузке сигналинг может не пройти;
- для соединения напрямую нужен доступный NAT; в редких сетях (строгий файрвол) P2P не поднимется.

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist
npm run preview    # посмотреть сборку
npm test           # юнит-тесты
```

## Деплой на GitHub Pages

В репозитории уже лежит workflow `.github/workflows/deploy.yml`: при пуше в `main` он собирает проект и публикует `dist`.

1. Push в `main`.
2. Settings → Pages → Source: **GitHub Actions** (если ещё не выбрано).
3. Через минуту игра доступна по адресу `https://<user>.github.io/<repo>/`.

## Структура

```
src/
  core/      ввод, математика, ГСЧ
  data/      баланс: фигуры, оружие, боты, лут
  world/     генерация карты, тайлы, лучи видимости
  game/      состояние рейда, симуляция, снимки для сети
  render/    Canvas-рендер, туман войны, миникарта
  ui/        меню, HUD, лобби, инвентарь, результат
  net/       WebRTC + ntfy-сигналинг (PvP), друзья и присутствие
  audio/     синтез звука на WebAudio
  save.ts    стэш, магазин, страховка, прогресс в localStorage
```

## Технологии

TypeScript, Vite, Canvas 2D, WebRTC, ntfy, WebAudio, localStorage. Без фреймворков и внешних ассетов — весь арт и звук генерируются кодом.
