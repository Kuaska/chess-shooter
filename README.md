# Chess Shooter — рейд

Опен-ворлд шутер с видом сверху в шахматной вселенной: выбираешь фигуру, собираешь снаряжение, заходишь в рейд, ищешь лут и уходишь через эвакуацию. Есть туман войны, боты и PvP с друзьями по коду комнаты.

Игра целиком статическая и работает с GitHub Pages: клиент на Vite + TypeScript + Canvas 2D, без сервера и без ассетов.

## Управление

| Действие | Клавиатура / мышь | Телефон |
|---|---|---|
| Движение | WASD / стрелки | левый стик |
| Прицел и огонь | мышь + ЛКМ | правый стик |
| Спринт | Shift | стик до упора |
| Перезарядка | R | кнопка «Заряд» |
| Навык фигуры | Q | кнопка «Навык» |
| Обыскать / эвакуация | E | кнопка «Взять» |
| Оружие | 1–4 | — |
| Аптечка / стимулятор / плита | 5 / 6 / 7 | — |

## Фигуры

| Фигура | HP | Стамина | Скорость | Плюс | Навык |
|---|---|---|---|---|---|
| Пешка | 100 | 100 | 174 | +20% лута | Рывок |
| Конь | 112 | 132 | 180 | дешёвый спринт | Прыжок |
| Слон | 106 | 112 | 168 | враги дольше видны на миникарте | Прозрение |
| Ладья | 150 | 82 | 152 | крепче броня | Щит |
| Ферзь | 120 | 120 | 172 | быстрая перезарядка | Залп |

Смерть — хардкорная: оружие и броня теряются, остаётся пистолет. Лут попадает в стэш только после успешной эвакуации (4 секунды в зоне выхода).

## Карта

128×128 тайлов, четыре биома, центральный дворец с королём-боссом, три точки эвакуации, которые открываются по таймеру (110 / 230 / 350 секунд). Рейд длится 10 минут — не успел выйти, погиб.

Туман войны честный: стены и деревья перекрывают обзор, уже увиденные места остаются в памяти и на миникарте.

## PvP с друзьями

1. Один игрок нажимает «Создать PvP-комнату» и получает код из 5 символов.
2. Остальные вводят код в поле «Присоединиться» (до 4 игроков).
3. Хост нажимает «Начать рейд» — все попадают на одну карту с общими ботами.

Соединение — прямое (WebRTC DataChannel), хост авторитетен: он считает симуляцию и рассылает снимки состояния 30 раз в секунду. Для обмена сигналами используется публичный ntfy.sh (HTTP + SSE), поэтому сервер не нужен.

Ограничения PvP:

- вкладка хоста должна оставаться открытой;
- если хост погибает или выходит, рейд для остальных заканчивается;
- ntfy.sh публичный и с лимитами запросов — для дружеских игр этого достаточно;
- для соединения напрямую нужен доступный NAT; в редких сетях (строгий файрвол) P2P не поднимется.

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist
npm run preview    # посмотреть сборку
npm test           # юнит-тесты
```

## Деплой на GitHub Pages

В репозитории уже лежит workflow `.github/workflows/deploy.yml`: при пуше в `main` он собирает проект и публикует `dist`.

1. Push в `main`.
2. Settings → Pages → Source: **GitHub Actions** (если ещё не выбрано).
3. Через минуту игра доступна по адресу `https://<user>.github.io/<repo>/`.

## Структура

```
src/
  core/      ввод, математика, ГСЧ
  data/      баланс: фигуры, оружие, боты, лут
  world/     генерация карты, тайлы, лучи видимости
  game/      состояние рейда, симуляция, снимки для сети
  render/    Canvas-рендер, туман войны, миникарта
  ui/        меню, HUD, лобби, результат
  net/       WebRTC + ntfy-сигналинг (PvP)
  save.ts    стэш, магазин, прогресс в localStorage
```

## Технологии

TypeScript, Vite, Canvas 2D, WebRTC, ntfy.sh, localStorage. Без фреймворков и внешних ассетов — весь арт рисуется кодом.
